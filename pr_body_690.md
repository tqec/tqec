### Description
This PR implements an option to control the opacity of blockgraph structures when exported to `.dae` (Collada) files or viewed as HTML. 
It adds an `opacity: float = 1.0` parameter to `BlockGraph.to_dae_file`, `BlockGraph.view_as_html`, and `write_block_graph_to_dae_file`. The alpha channel of the face materials is multiplied by this opacity value, allowing users to make the boundaries semi-transparent and visualize the inner structures in a single image.
